GIF / APNG Maker 制作プロンプト

連番画像をブラウザだけでGIF・APNGへ変換するツールを再制作するための完全仕様です。

あなたはフロントエンドエンジニア、画像・アニメーション処理担当、UI/UX、パフォーマンス、QAを兼任してください。

ブラウザだけで連番PNG/JPG/WebPからGIFまたはAPNGを作れる「GIF / APNG Maker」を完成させてください。

・PNG / JPG / WebP入力
・最大100フレーム
・複数選択、ドラッグ＆ドロップ
・自然順ソート（frame_2をframe_10より前にする）
・フレーム一覧
・上へ / 下へ移動
・複製
・削除
・全削除
・順番反転
・各フレーム個別delay
・全フレームへdelay一括適用
・50 / 80 / 100 / 180 / 250msクイック設定
・通常再生
・逆再生
・往復（ピンポン）再生
・無限ループ
・1回
・指定回数
・出力サイズ指定
・200 / 320 / 466 / 512 / 1024プリセット
・1枚目サイズを採用
・Contain
・Cover
・Stretch
・透明背景
・背景色指定
・Canvasプレビュー
・再生 / 一時停止
・スクラブ
・現在フレーム表示
・総時間
・目安FPS

GIF：
・16 / 32 / 64 / 128 / 256色
・1bit透明を正しく扱う
・フレームdelay
・loop回数
・GIF完成Blobを保存
・利用ライブラリのライセンスを表示

APNG：
・RGBAフレームを利用
・各フレームdelay

・PNG Blobで保存
