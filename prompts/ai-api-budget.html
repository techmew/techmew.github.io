REPRODUCIBLE BUILD PROMPT

AI API料金・予算シミュレーターの再制作指示書

目的・計算式・データ形式・例外・アクセシビリティを含む、作り直し可能な仕様です。

制作目的

利用者が複数のLLM APIの入力、キャッシュ入力、出力の料金を、手入力の100万トークン単価で比較できる、無料・ログイン不要の静的Webアプリを作る。

仕様

  1. 全行にモデル識別名、通常入力単価、キャッシュ入力単価、出力単価、1回入力トークン、1回出力トークン、1日呼出数、キャッシュ入力比率を持つ。比較は最大12行。
  2. 共通条件は月日数1〜31、手入力円/USD為替、円の月額予算。いずれも入力直後に再計算。
  3. perRequestUSD=(inputTokens*(1-cachePct/100)*inputUSD + inputTokens*(cachePct/100)*cachedUSD + outputTokens*outputUSD)/1000000。
  4. dayUSD=perRequestUSD*callsPerDay、monthUSD=dayUSD*days、monthJPY=monthUSD*manualExchangeRate。
  5. 低コスト順の比較を助ける月額表・横棒チャートを表示。予算以内回数は、perRequestUSDが正なら floor((budgetJPY/fx)/perRequestUSD)。ゼロの場合は上限不能と明示。
  6. CSVはUTF-8 BOM付きで個別条件と試算結果を出力。JSONは版番号、共通設定、比較シナリオの構造で保存し、ファイル読込時に形式/サイズ/値を検証。
  7. localStorageは利用者が「端末へ保存」を明示操作した時だけ書込。復元・削除ボタンを設ける。
  8. ユーザーのテキストをHTMLへ挿入する場合は必ずエスケープ。APIキーは入力しない。外部通信・外部ライブラリ不要。
  9. スマホの横幅に合わせたカード入力、ラベル、キーボード操作、スクリーンリーダーに届く結果・状態通知を整備。

テスト手順

  • 100万入力トークン、キャッシュ率50%、通常入力1 USD、キャッシュ0.1 USD、出力0なら、1回0.55 USDになる。
  • キャッシュ0%と100%の境界、0回実行、予算0、無効なJSON、不正な数値、比較行の削除/複製を検証。
  • CSVの日本語列名、JSON復元後の再計算、保存ボタン未操作時にlocalStorageへ書かないことを確認。
  • 各種リンクとOGP、モバイル縦画面を確認する。

制約を明示

API価格や外国為替は自動取得せず、初期値は架空サンプルであることを大きく明示する。税、ツール料金、音声画像等は対象外。市場価格や利用実績を捏造しない。
