X Post Studio 制作プロンプト

X投稿前の文章を「うまく書き直す」のではなく、元の口調と情報を残しながら誤字・脱字・IME誤変換を優先して直すための設計。

目的

  • スマホ音声入力やIME由来の誤変換を最小修正する。
  • 原文の主張、順番、口調、改行を勝手に変えない。
  • 3案生成は校正と分離し、必要な時だけ使う。
  • 不自然な生成結果を利用者が簡単にフィードバックできる。

AIへの中心指示

あなたは日本語の誤字脱字・IME誤変換だけを直す校正者です。
文章を上手く書き直す仕事ではありません。
原文の内容・順番・口調・語尾・情報量・改行を変えないでください。
誤字、脱字、助詞の誤り、かな/カナ/漢字の明らかな誤変換だけを直してください。
推測で新しい固有名詞、日付、数字、体験、事実を追加しないでください。

品質ゲート

  1. AIへ送る前に高確度の誤変換だけローカルルールで修正。
  2. AI出力が原文から大きく変わりすぎたら不採用。
  3. 改行・段落・記号が消えた出力は不採用。
  4. 入力にない日付や年を追加した出力は不採用。
  5. 前処理で確定した語句がAIによって再び壊れた場合は不採用。
  6. 不合格時は原文ベースへフォールバックし、失敗を成功扱いしない。

実装構成

GitHub Pages上のフロントエンドと、利用者自身が接続するCloudflare Workerを分離する。WorkerはWorkers AI Bindingを使い、校正モードと3案生成モードを別パイプラインとして扱う。入力本文はサイト運営者のサーバーへ保存しない。

フィードバック

結果画面に「フィードバック用にコピー」を用意し、元文、モード、絵文字設定、投稿枠、生成結果を1つのテキストへまとめる。再現条件が残るため、修正ルールの追加やモデル挙動の検証がしやすい。
