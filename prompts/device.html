DEVICE

スマホ機能、3D表現、アクセシビリティ、完成条件までまとめた制作指示。

公開用編集

秘密情報や個人情報は除外。内容は制作時の指示を読みやすく整理しています。

スマートフォンというハードウェアそのものを使う、フォトリアル寄りの3Dパズルゲームを制作する。

最優先順位：
1. 面白いこと
2. スマートフォンならではであること
3. 3D世界のリアリティ
4. DEVICEを触っている感覚
5. パズルとして納得できること
6. 実際に動作すること

入力候補：
タッチ、ジャイロ、加速度、Face Up / Face Down、カメラ代表色、マイク音量、振動、スピーカー、明るさ、コンパス、充電状態、バッテリー、現在時刻。

代表ステージ：
・暗闇の迷路：画面を見ず振動だけで出口を探す
・DON'T LOOK：端末を伏せると内部機構が変形
・STEAL COLOR：現実世界の色をカメラで取り込み装置へ送る
・STAY STILL：振るのではなく完全静止が正解
・POWER：充電開始を演出に利用。未対応端末には代替操作

アクセシビリティ：
センサー非搭載、権限拒否、振動OFFでも進行不能にしない。音パズルには視覚補助、色には色覚補助を用意する。激しい端末操作は要求しない。

技術構成：
Unity 6系 + C#、モバイルURP。
SensorManager / PuzzleManager / GameStateManager / AudioManager / HapticsManager / PermissionManager / SaveManager / AccessibilityManager / DeviceCapabilityManager を分離し、実機入力・Editor疑似入力・未対応端末フォールバックを切り替えられるようにする。

説明だけで終わらず、プロジェクト・コード・シーン・UI・センサー・パズル・セーブ・ビルド設定・README・Androidテスト手順を成果物として残す。

このプロンプトは「正解例」ではなく、実際の制作過程を再利用できる資料として公開しています。
