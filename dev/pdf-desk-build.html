PDF Meta Desk 制作記録

「作りやすいからまた画像変換」を避け、既存7本と用途が重ならない文書系ツールとしてPDF Meta Deskを選んだ過程を残します。

開始時に確認した既存制作物

公開中のWebアプリは、Image Slimmer、HEIC Lab、GIF / APNG Maker、LINEスタンプメーカー、Exif Cleaner、Watch Motion Studio PRO、SNS Image Studioの7本でした。画像・クリエイター系へ偏っていたため、同系統の新規画像ツールは優先度を下げました。

PDF Meta Deskを別アプリにした理由

Exif Cleanerも「情報を確認して削除」しますが、入力は画像、出力は再生成画像、中心処理は画像メタデータとCanvasです。PDF Meta Deskは入力がPDF、出力もPDF、中心処理がページツリーとPDF Document Info / XMPで、結合・抽出・削除・回転・分割という文書操作が主です。既存ツールへの機能追加では利用フローが崩れるため分離しました。

競合を見て変えたところ

2026年9月26日時点で、ブラウザ内だけでPDFを処理する無料ツールはすでに複数あります。単なる「結合・分割」だけでは新規性が薄いので、PDF Meta Deskではページ整理とメタデータ検査・削除を同じ画面に置くことを軸にしました。

  • Foliant：ローカル処理型のPDF編集・整理
  • Creator Privacy Kit：ローカルPDFツール群
  • Kept Local：ブラウザ内PDFツールの比較記事

今回実装した機能

  • PDF最大20ファイル、合計200MB
  • 複数PDFの並べ替えと結合
  • ページ範囲の抽出
  • 指定ページ削除
  • 90度単位の回転
  • 複数範囲への分割とZIP保存
  • Title / Author / Subject / Keywords / Creator / Producer / 作成日時 / 更新日時 / XMPの検査
  • Document InfoとXMPの削除
  • 出力PDFの再読込とページ数検証
  • メタデータ削除後の再検査
  • 操作履歴は内容を保存せず、操作名だけlocalStorageへ保存

テストで確認したこと

実装コードはJavaScript構文チェックを通し、ページ範囲パーサーでは単ページ、カンマ区切り、範囲、重複、上限超過を分けて扱うようにしました。出力は「saveできた」で終わらせず、もう一度pdf-libで読み込み、期待ページ数と一致した時だけ結果欄へ出します。

意図的に入れなかったもの

OCR、PDF圧縮、本文のRedaction、電子署名の保持・付与は、雑に混ぜると「できたように見えるだけ」になりやすいため初版には入れていません。とくに黒い四角を重ねただけの処理を個人情報削除として扱うのは避けました。
