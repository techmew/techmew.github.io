# BEATBOUND — 星喰いの戦旗

オリジナルのブラウザ用リズム戦略ゲーム。インストール不要です。

## プレイ
https://techmew.github.io/beatbound/

## 操作
- PC：Q / W / E / R または 1 / 2 / 3 / 4
- スマートフォン：画面下の4つの太鼓をタップ
- 4拍のコマンド入力 → 次の4拍で部隊が行動

## コマンド
- 前進：TA TA TA DUM
- 攻撃：DUM DUM TA DUM
- 防御：KAH KAH TA DUM
- 溜め：DUM DUM KAH KAH
- 後退：TA TA KAH TA
- 星光の奇跡：TING DUM TING DUM（FEVER＋チャージ2必要）

全6ステージ、6ボス、FEVER、部隊強化、ローカルセーブ対応。

本作はキャラクター・名称・音楽・世界観を独自制作した作品です。
