# 番人の予備動作・反撃と死亡後の学習
作業元 main 9a7beab。game.js、英訳、index.html、番人と死亡の回帰テストを更新。
- 近くの番人が攻撃を構えると、地面に攻撃の向き、頭上に発動までのゲージを表示。空振り直後は表示と色が変わり、隙の残り時間を示す。単独番人の箱にも奪取の残り時間を表示する。
- 空振り後の1.6秒は、攻撃を当てるとその一撃のダメージが30％増える。反撃と奪取は同じ隙を使い、反撃を当てればその回の奪取機会は終了する。複数番人にも反撃は可能で、箱の奪取条件は単独戦に限る。
- 通常近接・突進・水辺の強敵の直接攻撃、餓死、毒の致死時に原因を記録。結果画面には対応する回避・食事などの手掛かりを表示。UFO・地割れは既存の死亡判定を使う。未対応の死因には従来の結果文を表示。
- 予告は既存の2D・3D共通表示に追加し、構え中の近距離・画面内の番人だけで矢印の端点を投影。新規テクスチャ、タイマー、パーティクルは追加していない。
- 検証。Node回帰36本。番人の構え・空振り・反撃での20→26・次撃20・奪取期限切れ・死亡原因と再挑戦の文言を検証。
- 製品版に向けた未完課題。初見プレイヤーに操作説明をせず、最初の食事と死因を自分で説明できるかを観察。Android実機で15分以上、街区移動・積雪・密集戦・ボス戦のフレーム時間を測る。中盤の動物ごとの攻略差と、100年ボス撃破から次の周回を始める動機を通しで評価する。
