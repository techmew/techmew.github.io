# 縦画面の重なりとフレーム負荷
作業元 main d7ddc52。提供された縦画面のイノシシ戦を対象に修正。

- 700 CSS px以下の縦画面は、地区と目的・生命等を左、操作ボタンとミニマップを右に分ける。長い目的は省略し、「詳細」で全文と年齢、季節、装備、巣、食料庫、ガイドを展開する。
- 番人の通常名札と戦闘用の札が同時に描かれる状態を解消。攻撃方向の矢印と「横へ回避」「反撃」の短い表示を使う。通常の敵は名前とLvを一行にし、四角い背景を外す。
- タッチ主体の端末で3Dだけ描画倍率を最大1.25にする。従来上限1.8の端末で3Dバッファの画素数は約52%減る。HUD・ミニマップの定期更新は0.14秒から0.24秒へ。隠れた季節レイヤーの全面消去を停止。視線の範囲外にある建物は壁・家具の細かい交差テストから除外する。
- Node回帰40本成功。固定した建物90棟・視線12000件の合成比較で旧版と全結果が一致（単発133ms→26ms）。ゲーム全体のFPSではない。
- 未検証：報告元のAndroid実機での縦画面目視、乱戦・降雪時のフレーム時間と長時間プレイ時の発熱。
