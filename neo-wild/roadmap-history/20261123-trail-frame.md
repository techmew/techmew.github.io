# 積雪時のカクつきと東部の足跡追跡
作業元 main 763f515。対象は game.js、webgl3d.js、world-time.js、east-expedition.js、i18n 関連、読み込み元 HTML。
- 軽量化。積雪メッシュの微小な視点移動による再構築を抑制。2D は雪の輪郭を最大4096区画まで再利用し、増減水する区画は毎回計算。積雪量の履歴計算はゲーム内5秒ごと。ミニマップは余白付きの地形を再利用し、災害や目標・敵は現在位置を表示。日本語表示中の翻訳用 DOM 監視を停止。
- 遊び。東部で野生動物の新しい足跡から80以内で速度を落とすと、地域欄に獲物または危険な動物の足跡と表示し、ミニマップにその足が向いた方向を描画。雨と雷雨では4秒、通常は12秒で消える。
- 検証。Node 回帰34本通過。追加テストで足跡の向き・速度・距離・雨・同行個体の除外、ミニマップの移動と縮尺変更を確認。模擬WebGL・480×800・プレイヤー＋8頭・38フレームで移動と視点変更。積雪量0.47の雪面再構築38→1回。初回8フレーム除外後のCPU描画準備の中央値20.8→0.81ms、95パーセンタイル59.8→1.47ms。雪なしは中央値0.68→0.67ms。GPUと画面合成は計測対象外。
- 未検証。Android実機での長時間FPS、市街地の密集戦や地形キャッシュの切り替え時に残る停止時間。次は定期オートセーブの同期書き込みと街区をまたぐフレームを端末上で計測する。
