# EC商品説明 作成プロンプト

以下の入力表だけを根拠に、日本語の商品説明を作成してください。

## 絶対条件
- 入力にない仕様、効果、受賞歴、利用者レビュー、比較優位を作らない。
- 不明点は「要確認」と明記し、推測で埋めない。
- 価格・在庫・送料・保証は、根拠URLと確認日がない限り断定しない。
- 医療、健康、安全、法令に関わる表現は販売者の確認対象として分離する。
- 商品写真・ロゴ・第三者素材の利用権は確認済み欄を参照する。

## 出力
1. 商品タイトル案（45字以内）3案
2. 一文要約（80字以内）
3. 購入者の疑問に答える箇条書き5点
4. 商品説明（300〜500字）
5. FAQ 3問
6. 注意事項・要確認事項
7. CTA 2案（誇張なし）
8. 使用した根拠URL一覧

## 入力
ここに intake-sheet.csv の1行を貼り付ける。
