EC商品説明スターター

NEW2026年10月15日公開

商品名だけで説明文を量産せず、事実・購入者の疑問・注意点を先に揃えるための無料4点セットです。入力シート、AI用プロンプト、架空商品の納品見本、公開前チェックリストをそのまま保存できます。

含まれるもの
  • 商品情報入力シート（CSV）
  • 説明文作成プロンプト（Markdown）
  • 架空商品の納品見本（Markdown）
  • 事実・権利・表示の公開前チェックリスト（Markdown）

入力シートをダウンロード プロンプトを見る

使い方

  1. 入力シートに公式仕様、対象者、使用場面、注意点、根拠URLを記入します。
  2. 未確認欄を残したままプロンプトへ渡し、AIに「不明」と書かせます。
  3. 納品見本と同じ順序で、タイトル、要点、本文、FAQ、CTAを整えます。
  4. 公開前チェックリストで誇張、価格、権利、リンクを人が確認します。

この見本がしないこと

  • 存在しないレビュー、実績、利用者の声を作りません。
  • 確認できない効能、比較優位、価格を断定しません。
  • 商品写真やブランド素材の利用権を自動で保証しません。
  • 各モール・業界の表示義務を代替しません。
販売状況

このページの4点セットは無料です。有料版・代行サービスは現在販売中として案内していません。販売ページが公開・確認できた場合のみ、ここに正規の購入先を追加します。
