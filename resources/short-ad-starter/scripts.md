# 15秒店舗広告 台本スターター
ひまねこラボ / v1.0 / 2026-10-14

## 内容と使い方
3業種の台本例、読み上げプロンプト、公開前のチェック。音声・動画・画像は付属しません。
秒数は編集上の目安です。音声を実際に読み上げ、尺を測って調整してください。
【 】内を本人が確認した事実へ置き換え、未入力のまま公開しないでください。
サンプルは実店舗や顧客の実績ではありません。

## 1. カフェの新メニュー
- 0〜3秒 / 映像: 店舗が撮影した商品の寄り / 字幕: 【商品名】 / 音声: 「今日の一杯に、【商品名】。」
- 3〜8秒 / 映像: 注ぐ動作や断面 / 字幕: 【確認済みの特徴1つ】 / 音声: 「【確認済みの特徴を短く説明】。」
- 8〜12秒 / 映像: 価格と提供日 / 字幕: 【税込価格】・【提供期間】 / 音声: 「【税込価格】、【提供期間】にご用意しています。」
- 12〜15秒 / 映像: 店名と確認先 / 字幕: 詳細は【確認先】 / 音声: 「詳しくは【店名】の【確認先】へ。」
冒頭の別案A: 「【商品名】、【提供開始日】から。」
冒頭の別案B: 「【味・材料など確認できる特徴】の一杯です。」
冒頭の別案C: 「今日のメニューをご紹介します。」

## 2. サロンのメニュー案内
- 0〜3秒 / 映像: 清潔な店内 / 字幕: 【メニュー名】 / 音声: 「【店名】の【メニュー名】をご紹介。」
- 3〜8秒 / 映像: 許諾のある施術工程 / 字幕: 【内容・所要時間】 / 音声: 「【確認済みのサービス内容】をご提供します。」
- 8〜12秒 / 映像: 料金と予約手段 / 字幕: 【税込価格】・【予約方法】 / 音声: 「【税込価格】。予約は【予約方法】から。」
- 12〜15秒 / 映像: 詳細ページ / 字幕: 条件・空き状況は【確認先】 / 音声: 「詳しい内容と空き状況は、【確認先】をご確認ください。」
確認: 効果・変化・治療を保証しない。写真の人物から掲載許諾を得る。未確認のBefore/Afterは使わない。

## 3. ハンドメイド商品の紹介
- 0〜3秒 / 映像: 実物写真 / 字幕: 【商品名】 / 音声: 「【商品名】を作りました。」
- 3〜8秒 / 映像: 素材とサイズ / 字幕: 【素材】・【サイズ】 / 音声: 「【素材】を使った、【サイズ・仕様】です。」
- 8〜12秒 / 映像: 使用場面 / 字幕: 【税込価格】・送料【送料条件】 / 音声: 「価格は【税込価格】。送料は【送料条件】です。」
- 12〜15秒 / 映像: 商品ページ / 字幕: 詳細は【ショップ名】 / 音声: 「色や在庫は【ショップ名】でご確認ください。」
確認: 実物と異なる色・材質・機能をAIで補わない。完売や再入荷の情報を実際に確認する。

## AIに台本を整えてもらう指示
次の確認済み商品情報だけを使って、15秒を目標とした日本語広告台本を整えてください。
入力にない実績・人気・口コミ・効能・割引・在庫・限定期間を追加しないでください。
未入力の情報は「要確認」のままにし、推測しないでください。
出力: 秒数の目安 / 映像 / 字幕 / 音声 / 要確認事項。
商品情報: 【入力】
公開前に人が事実と読み方を確認し、実際に読み上げて尺を測ります。

## 公開前チェック
- 商品名・税込価格・送料・営業時間・提供期間は確認済みか
- 人物・声・素材の掲載と商用利用を許可されているか
- 生成時のプランと機能が商用利用を認めているか
- 数字や店名の読み、音量、字幕、映像と音声の一致を確認したか
- 実績・売れ行き・口コミを捏造していないか
- 掲載先で必要な広告表示・AI表示を確認したか
- 元台本、生成日、公開版、確認者を記録したか

## 利用条件
本サンプルの文章は、利用者自身の広告・顧客案件向けに編集して商用利用できます。
本サンプルをそのまま有料商品として再配布・再販売することはできません。
クレジット表記は任意です。AIサービスや外部素材の利用許諾は含まれません。
効果・販売数・掲載許可は保証しません。2026-10-14版。
