# OTODAMA ∞ 〜声から生まれるバトル〜 (v0.2)

## 更新内容

- 声を約3秒解析してキャラクターと能力値を生成。マイク許可エラーを判別し画面に原因を表示。
- キャラ外見: 体型5、目/眉/鼻/口/耳各20、左右腕各30、10カラーを維持。さらに12種族、30頭飾り、16背面装飾、24模様、16脚パターンを追加。これらの掛け合わせは「数万種類」を大幅に超えるが、全パターンの絵柄の違いを保証するものではない。
- 名前: 64タイトル × 64第1音節 × 64第2音節 × 128語尾 = **33,554,432通り**。同じ名前が複数回生成されることはありうる。
- COM戦、30体までの端末内保存を維持。
- オンライン: 新規 `/random` マッチング待機列を実装。2人揃ったら同じ部屋へ遷移し、準備を自動的に完了してバトル。従来の友達招待（コード）も利用可能。

## マイクが使えない場合

`getUserMedia` は原則HTTPS（またはlocalhostなど安全な環境）と利用者の許可が必要です。AndroidでHTMLファイルを直接開いた場合やChatGPT等のプレビュー内では、端末/ブラウザによりブロックされることがあります。**実際のゲームサイトをHTTPSで公開してChromeで直接開いてください。**

1. Chromeのサイト設定で対象サイトの「マイク」を許可。
2. Androidの「設定」→「アプリ」→「Chrome」→「権限」→「マイク」を許可し、Androidのマイクアクセス全体がオフでないか確認。
3. サイトを再読み込みし、「声からキャラ生成」をタップして許可ダイアログを操作。
4. マイクを利用できない場合も「おためし生成」からCOM戦を試せます。

録音ファイルはサーバーへ送信しません。音声特徴量・キャラの能力などはオンライン対戦で送信されます。

## オンライン対戦を使うには（本ZIPにはサーバーコードのみ、サーバー未公開）

必要なもの: Cloudflareアカウント、PCのNode.js、静的HTMLを公開するHTTPSサイト。

1. フォルダで `npm install`。
2. `npx wrangler login`。
3. `npm run deploy:server`。
4. 出力された Worker のURL（例: `https://otodama-room.<アカウント>.workers.dev`）をコピー。
5. `index.html` を GitHub Pages か Cloudflare Pages にアップロード。HTTPSのゲームURLを取得。
6. HTTPSのゲームページから対戦サーバーURLを入力して「接続先保存」。両プレイヤーとも同じWorkerを指定。
7. 「ランダムマッチ開始」で相手待機。2人揃うと自動でマッチし対戦開始。

ページを公開する際、`index.html` の `DEFAULT_SERVER_URL` に公開済みWorkerのURLを入れると、利用者の手入力は不要。

無料枠には利用量の制限があります。1つの待機列を使う最初の試作なので、大規模運用を想定していません。チート対策、サーバー側の音声真正性検証、認証・レート制限・ランキング・対戦履歴の保存は未実装です。実際のインターネット2端末間の接続試験は未実施。

## 収録ファイル
- `index.html`: 声解析、キャラ生成、バトル、ランダムマッチUI
- `worker.js`: Cloudflare Workers + Durable Objects サーバー (Room, Matchmaker)
- `wrangler.jsonc`: Cloudflare構成 (既存Room v1 + 追加Matchmaker v2 migration)
- `package.json`: `wrangler` スクリプト
- `test-matchmaker.cjs`: ロジック単体テスト。`node test-matchmaker.cjs` で実行。

文字ブレードのソース・画像・キャラは使用していません。
