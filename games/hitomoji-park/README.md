# ひともじ遊園

文字の形で遊ぶ、4-in-1の日本語ブラウザゲーム。

プレイ: https://techmew.github.io/games/hitomoji-park/

## 4つのゲーム

| ゲーム | 操作 | ルール |
| --- | --- | --- |
| 一文字つり | 文字を押したままドラッグ、離して釣り上げる | 漢字・ひらがなの実際の描画ピクセルで魚を捕まえる。35秒。 |
| 名前ダッシュ | タップ / スペースでジャンプ | 名前の字形が移動速度に影響。障害物を飛び越えて3人で競争。 |
| ひとこと屋根 | 画面を押した位置へ屋根を移動 | 言葉の実際の塗り部分で雨や石を防ぐ。3人を25秒守る。 |
| 漢字タワー | タップ / スペースで文字を落とす | 文字輪郭との接触を計算し、支持範囲と重心で積み上げを判定。3ミスで終了。 |

## 実装

- `index.html` のみで動作。外部JS・CSS・画像・CDN不要。
- HTML Canvas 2Dで描画。日本語フォントの文字をオフスクリーンCanvasに描き、アルファ値から当たり判定を作成。
- レスポンシブ表示・タッチ操作・マウス操作・キーボードのスペースキーに対応。
- ベスト記録と入力文字はブラウザの `localStorage` に保存。端末間の同期・サーバー側ランキングはない。
- 効果音はブラウザのWeb Audio API。画面右上でOFF可能。
- 「結果をシェア」はWeb Share API、非対応ブラウザではクリップボードにコピー。
- 文字の表示形状は端末にインストールされた日本語フォントによって多少変わる。
