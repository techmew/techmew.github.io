# 存在しない11人目 ― 霧立荘編

吹雪で閉ざされた山荘で、旧友たちが再会する。十一年前に起きた失踪、切れた集合写真、持ち主のわからない招待状。これは「誰を信じるか」を選ぶオリジナルの分岐型サウンドノベルです。

## ブラウザで遊ぶ
https://techmew.github.io/games/eleventh-witness/

## 現状
**第一夜『席を空けておいて』公開版**。物語全体は制作途中です。第一夜には10の選択箇所と、進行上の2種類の結末が用意されています。初版の無機質なSF施設デモとは別のシナリオとインターフェースに全変更しました。

## 操作
- 文章の表示後、背景・テキストのどこでもタップで進行。読み出し中は1回目のタップで全文表示。
- 背景をドラッグすると上下左右を少し見回せます。「◎」で正面へ戻せます。
- 上段「履歴」「手がかり」「しおり」「設定」。
- 下段「自動」「既読」「音 OFF/ON」。
- しおりは3個。進行も自動保存。セーブデータはこのブラウザの端末内に保存されます。

## 開発者向け
- index.html：ゲームの画面とスタイル
- story.js：第一夜の本文、選択肢、場面接続、手がかり
- engine.js：描画・文字送り・分岐・音響・セーブ・入力
- assets/reboot-*.svg：本版用の新規オリジナル背景5点
- STORY_BIBLE.md：リブート正史の制作基準
- PROGRESS.md：実作業・テストログ
- FEEDBACK.md：ユーザー／Xからの実際の要望
- POST_QUEUE.md：Buffer/X投稿保留
旧SF施設の画像とenhancements.jsは新画面から切り離しています。旧Git履歴は必要なら復帰可能です。

## 評価基準
綺麗なUI、単なる選択肢数、文字数、雰囲気だけで完成宣言しません。人間関係・怪異の因果・論理的な殺人トリック・バッドエンドの必然性・真エンディングの納得感を満たすまで増補・推敲を続けます。
