# 存在しない11人目 / THE ELEVENTH WITNESS
オリジナルの無料ブラウザ推理サウンドノベル。第0章「録音された最期」試作版。

## プレイ
https://techmew.github.io/games/eleventh-witness/

## 現在実装済み
- 背景2点、独自SVGキャラクター立ち絵3点
- 分岐のない第0章の導入とキャラクター会話
- 証拠3件の現場調査
- WebAudioの音響指紋を聞き比べる推理
- 証言と証拠の組合せによる矛盾追及
- 記録再構成の推理
- 自動保存と再読時の変化
- 音声ON/OFF、文字サイズ、証拠帳、会話ログ、モバイル表示

## 操作
会話：タップ、Enter、Space。推理：画面の選択肢。右上の「証拠」「履歴」「設定」から情報を確認可能。
進行はブラウザのlocalStorageへ保存されます。音声がない端末でも進行できます。

## 開発ファイル
- STORY_BIBLE.md：作品制作上の基本方針・公開可能な構成
- PROGRESS.md：実行ごとの実装・テスト・続き
- FEEDBACK.md：X等で確認済みの利用者意見・採否
- POST_QUEUE.md：X投稿草案・Buffer送信状態

## 2026-10-20 操作改善
- **背景上で上下左右に指をドラッグ**：視点を滑らせる（2.5D疑似カメラ）
- **「◎ 視点を戻す」**：背景の視点位置を中央へ戻す
- **会話中は背景・テキスト枠のどこをタップしても次へ**
- **開始画面は「最初から始める」またはタイトル画面の空白部タップで開始**
- **推理中**は証拠選択肢をタップする。誤タップで会話が進むことはない。
