## 毎回の完了条件

1. GitHub mainの最新版を読んで、対象回次の改善を実装。コード変更のcommitが成功したら1回として計上。
2. 最低でも構文、起動、操作、敵、武器、ボス、BGMの回帰テストを可能な範囲で実施。
3. このファイルの対応チェックを `[x]` に更新し、短い変更概要・commit SHA・試験結果を追記。
4. 試験失敗・GitHub反映失敗の場合はチェックを付けず、次回その修正から再開。

## 完成判定

- 3ステージに分岐があり、選択で敵・報酬・見た目が実際に変わる。
- 周回ごとの敵編隊・装備・イベントに変化があり、最低10周のうち内容の違いを確認できる。
- 突然の被弾や回避不能配置を避け、攻撃予告が明確。スマホ横向きで機体が指に隠れない。
- 途中開始・一時停止・ゲームオーバー・クリア・再挑戦が破綻しない。音声のON/OFF、複数画面サイズを確認。
- ボス・報酬・性能・フレーム数のテストを通過。新規プレイヤーへの説明は短い。
- 最終的なGitHub公開URLを実際に検証できれば検証結果を記載。公開先が未確認なら未確認と明記。
