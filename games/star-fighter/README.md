# STAR FIGHTER

オリジナルの横スクロールシューティングゲーム。HTML / Canvas 2D / JavaScript のみで動き、外部ライブラリやアセットは不要。

## Play
https://techmew.github.io/games/star-fighter/

## 操作
- **PC**: WASD / 矢印キーで移動、X で強化項目の選択、Enter / Z で強化、Space で衝撃波、P で一時停止、M で音声切替
- **スマートフォン（縦・横画面対応）**: 左の広いタッチパッド上をなぞると、指の相対移動量に応じて機体が即座に動きます。タップした位置へ飛ぶ方式ではありません。右側に「タイトルへ」「一時停止/再開」「最大化」「衝撃波」「強化」を配置。装備は画面下の6種類から選択します
- 自動射撃。パワーカプセルを集め、BOOST / SPREAD / LASER / MISSILE / OPTION / SHIELD を選択して「強化」で購入（残額保持）

## 初期収録
- 3つのエリアと独立した背景演出
- 3種類の大型ボスと複数の攻撃パターン
- 敵の編隊、予告付き突撃敵、誘導ミサイル、僚機、貫通レーザー、バリア、衝撃波
- ボスは耐久力55%以下で第2形態に突入し、予告付きビームと新しい弾幕を使用
- 敵撃破・敵弾かすり回避でOVERDRIVEが蓄積。発動時8秒間、火力・連射・得点が増加
- GRAZE（弾かすり）ボーナス、MAX CHAIN記録、スコア倍率
- スコアとコンボ倍率、ローカル保存のベストスコア
- プロシージャル描画・パーティクル・オリジナルのサイバーテクノBGM（3ステージ＋ボスアレンジ）
- モバイル縦横画面対応、相対タッチパッド、キーボード操作、一時停止

## BGM
Web Audio API でリアルタイム合成する完全オリジナルのサイバー系BGMです。音源ファイル・外部楽曲・第三者サンプル不使用で、ゲーム内で無償利用できます。

## 分岐航路（開発工程 01）

ボス撃破後に2航路から選択します。安全航路は編隊が小さく、敵の出現・攻撃が緩やかで、回収範囲と物資ドロップが増加します。危険航路は高速編隊・迎撃機・重装敵の出現率、敵の耐久・攻撃頻度、ボス耐久が増加する代わりに、カプセル2個・撃破得点+25%・オーバードライブ蓄積を獲得します。両ルートとも敵数の上限を設け、ステージ2・3の背景色と編成も変化します。PC は 1 / 2 キー、スマートフォンは2枚のカードをタップして選択できます。

## 航路マップ（開発工程 03）

ボス撃破後の航路選択画面に、3セクターのマップ・踏破した経路・現在地・次の分岐を表示。現在地は青緑色の機体マーカー、踏破経路は緑色の線、選択可能な経路は青または橙の破線。画面上部のエリア表示は現在の航路名に変わります。PCの左右キーで選択中のカードとマップの強調表示が同期します。

## シードによる再現（改修 04）

- タイトルの SEED 欄を空欄にして開始すると、毎周新しい8桁の16進シードを生成します。8桁以内の16進数を入力すると指定シードで開始できます。
- ゲームオーバー／クリア画面にシードを表示し、「同じ配置で再挑戦」で再利用できます。URL の `?seed=1A2B3C4D` でも指定できます。
- 敵編隊の抽選、敵初期パラメータ、発射間隔、補給位置・ドロップは、ステージ・航路ごとに分離したシード付き乱数を使います。パーティクル・描画・BGMの乱数消費は敵配置を変えません。
- 再現の条件：**同じシード、同じ航路、同じプレイヤー行動・経過時間**。フレーム時間や撃破順序が異なる場合、出現回数・ドロップのタイミングは変化し得ます。完全なリプレイ記録やフレーム固定シミュレーションは未実装です。

## 航路連鎖とランダムイベント（改修 05）

- シードと直前の航路に応じて、次の2つの航路名と固有イベントを生成します。航路マップは未到達地点を「未発見」とし、次の候補だけを表示します。
- 安全航路のイベント：漂流物資、修復ビーコン、旧式補給庫、青い共鳴。戦闘途中に補給や防御・ドライブ回復が発生します。
- 危険航路のイベント：追撃隊、プラズマ嵐、武装貨物船、重力の裂け目。戦闘途中に特殊編隊が登場し、光る精鋭を倒すとカプセルを確定獲得します。
- 同じ危険度の航路を2回連続で選ぶと連鎖ボーナス：安全×2はバリア+1、危険×2はドライブ+20（ただし危険イベントには追加敵1機）。航路カードでイベントを確認でき、PC 1/2 またはタップで選択できます。
- イベントはゲーム進行時間で1回のみ発生。シードと分岐を再利用すると同じイベントを再現できます。

## セクター再開（改修 06）

ブラウザの localStorage に**セクター開始時とボス撃破後の航路選択時**のチェックポイントを自動保存します。再読み込み後はタイトルの「CONTINUE」でその境界から再開できます。戦闘中の途中位置・敵弾は保存しません。ルート、シード、装備、残機、得点、イベント状態を引き継ぎます。ゲームオーバー／全ステージクリア時はチェックポイントを削除し、同一シード再挑戦は従来どおり利用できます。ブラウザの保存機能が使えない場合も通常プレイできます。

## 編隊の出現安全性（開発工程 08）

各編隊は出現前にシード再現可能な配置調整を行い、敵同士の初期位置の重複を避けます。出現予告には青緑の「SAFE」レーンを表示し、敵の初期進入位置に通行できる縦方向の余白を確保します。これは**出現時の目安**であり、後から移動する敵や追尾弾に対する無敵エリアではありません。予告時間は1.35秒です。

## 敵編隊AI（工程09）

敵の移動は機種・編隊ごとに変化します。偵察機は波形飛行、突撃機は上下挟撃、重装艦の護衛は旗艦の移動に追従します。編隊によっては最大3機が約0.9秒の照準予告後に同時攻撃します。予告時点の位置へ照準が固定されるため、移動して回避できます。シード再現性と編隊出現時の安全レーンを維持します。

## 全画面プレイ（縦横両対応）

- 画面上の **⛶ 全画面** ボタンで全画面／通常表示を切り替える。PCでは **F** キーでも切替可能。
- 対応するスマホブラウザでは **MISSION START / CONTINUE / 同じ配置で再挑戦** をタップしたときに全画面表示を試みる（ユーザー操作が必要）。
- ブラウザが全画面APIをサポートしない場合、ホーム画面に追加してアプリとして起動すると、`manifest.webmanifest` の全画面・端末向き追従設定が使われる場合がある。ブラウザ／OSによってはアドレスバーを完全に非表示にできない。
- 全画面でも左タッチパッド・右側操作パネル・武器強化・パルス・ポーズ・BGMを維持。既存の36回改修工程の外で行った表示修正。

## 敵の出現強度と救済（改修 10）

敵の出現ペースと編隊規模は、セクターの進行、選択した航路、画面上の敵・敵弾密度、残機・装甲状態をもとに内部で自動調整します。危険航路は高圧の編隊が出やすく報酬も従来どおり高め、安全航路は小規模編隊と回収優先。出現時の安全レーン予告（1.35秒）は維持し、編隊の最大機数は4〜8機に制限します。被弾時は一時的に出現間隔を広げ、連携攻撃を抑えて立て直しの時間を確保します。画面に複雑な難度数値は表示しません。難度判定は描画・音声の乱数を使わず、同一シード・同一操作・同一経過時間で再現できます。

## 地形ギミック（工程11）

各セクターでシードに応じて2回、**漂流残骸（DEBRIS）**または**イオン障壁（ION FIELD）**が出現します。危険な2レーンと安全な1レーンを**2.1秒前**から色分け表示。安全レーンは予告開始時の自機位置に最も近い場所を選び、初見でも回避しやすくしています。地形の通過中は新規敵編隊と航路イベントを延期し、同時攻撃を抑制。残骸は射撃で破壊可能、衝撃波は両地形を除去できます。ボス開始・ステージ終了・再開時は地形をリセット。HUDに新しい数値は追加しません。

## 操作UI緊急改修（2026-10-29）

- 旧小型スティックと縦画面ブロックを撤去。横画面は左サイド全体をタッチパッドに、右にタイトル・ポーズ/再開・最大化・衝撃波・強化を配置。縦画面は上に16:9のゲーム画面、下にタッチパッドと右ボタンを並べる。
- タッチパッドのポインタ移動は `pointermove` と相対差分を使い、入力時の機体座標/目標座標を同時更新。タッチした瞬間の機体ジャンプと従来のスティックのデッドゾーンを解消。キーボードの追従係数も増強。
- タッチ端末のCanvas描画解像度をDPR 1に調整し、描画負荷を軽減（鮮明さとのトレードオフ）。縦向きでの自動停止と全画面時の横向きロックを解除。

## 100シード・安全配置回帰（工程12）

`node games/star-fighter/qa_100_runs.js`（リポジトリルートから）または `cd games/star-fighter && node qa_100_runs.js` で標準ライブラリのみの自動テストを実行できます。テストはゲームの最新ソースを仮想DOMとCanvasで起動し、100シード・500セクター/航路設定で8,000編隊、30,789機の初期配置、1,000地形候補、15種編隊の警告・安全レーン・初期重複・シード再現を検査します。さらに100シード×3ステージの実更新ループ（計408,300回、無敵の模擬プレイヤー）で各セクター2回の地形予告、航路イベント、敵/敵弾数上限、地形と編隊の非重複を確認します。これは実プレイヤーの攻略可能性・被弾率を証明するものではありません。

実装上の対策：地形の約6秒前から新しい編隊・イベントを待機させ、残存敵を退避させて追加射撃を止め、弾が自然消滅してから2.1秒予告の地形を出現させます。地形中の新編隊を防止し、敵弾の同時表示上限を120発に制限。操作ボタンの「一時停止／再開」表示もタイトル帰還・再出撃時に正しく戻します。初期配置の安全帯は保証しますが、プレイヤー操作・後続の敵弾を含む全状況での無被弾は保証しません。

## 13/36 — セクタークリア後のランダム3択報酬

第1面・第2面のボスを倒すと、航路選択の前に**3つの報酬から1つを選択**する画面が表示される。スマホはカードをタップ、PCは1・2・3キーまたは左右キーとEnterで決定。報酬はカプセル、衝撃波、バリア、装甲修復、ドライブ充填、残機、武器レベル、スコアの8系統から選ばれる。現在の所持上限に達した資源は候補から除外し、すべて上限の場合もスコア報酬を選べる。

抽選は周回シード・ステージ・航路で決定し、敵編隊の乱数とは独立。同じシードと同じ戦闘結果・所持状態なら同じ3択になる。報酬画面で終了してもCONTINUEから再開でき、受取後は次の航路選択地点から再開するため二重受取はできない。3面クリア時は報酬画面を挟まずエンディングへ進む。既存の全画面自動横向き・上部システムボタン・右側2操作ボタン・ゲーム画面内6色強化バー・ステージ別BGMは維持。

検査：JavaScript構文・仮想DOMの100シード×3ステージの回帰 **1,000,421/1,000,421**、静的UI検査 **7/7** 通過。スマホ実機表示・入力遅延/fps・公開反映は未確認。

## 14/36 — 周回限定パッシブ6種

第1・第2セクターのボス後の3択報酬でパッシブを獲得できる。未上限のパッシブがある場合、候補に必ず1つ以上含まれる。同一シード・同じ選択状態で報酬候補を再現する。各パッシブは最大Lv2、周回終了で初期化され、恒久強化にはならない。

- **高速給弾**：自動射撃間隔を1段につき12%短縮。
- **回収磁場**：補給品の吸引半径を+70、吸引速度を+65。
- **蓄電回路**：ドライブ充填量を+22%。
- **再生装甲**：取得時にバリア+1、次セクター開始時にさらにLv分補給（上限5）。
- **衝撃増幅**：衝撃波の敵・ボスへのダメージを+30%。
- **回収解析**：敵撃破時の補給品ドロップ率を+7%（上限65%）。

報酬画面に所持パッシブを小さく表示。既存の6色武器メーター、左パッド、右側2ボタン、ステージ別BGMは維持。チェックポイントは旧形式も読み込み、パッシブ情報がない場合は0ランクとする。ヘッドレス回帰1,000,542項目合格、実スマホの見た目・操作遅延・fpsは未確認。
