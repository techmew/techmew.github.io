# STAR FIGHTER — 操作・検証ガイド

8ステージのオリジナル横スクロールSTG。HTML5 Canvas 2D / JavaScript / Web Audioのみで動作し、第三者の音源・画像・外部ライブラリは使用しません。

**公開先：** https://techmew.github.io/games/star-fighter/

**開発状況（2026-10-30）：35/36、8/8ステージ実装済み。v1.0完成判定は保留。** 自動回帰テストは通過していますが、Android/iPhoneの実機表示、Bluetoothゲームパッド、入力遅延・FPSは未測定です。タイトルの「PREVIEW / QA」はこの状態を示します。36工程の正本は `DEVELOPMENT_PLAN.md` です。

## 操作

スマートフォンは**縦・横の両方**でプレイ可能。画面上部に「タイトル」「一時停止／再開」「最大化」「BGM」「縦横切替」、左に広い相対移動タッチパッド、右に**ノヴァ／強化の2ボタン**があります。射撃は自動です。

- **スマホ移動：** 左パッドを指でスワイプ。指の動いた分だけ機体が動き、触れた位置にワープしません。指を離せば停止。
- **PC：** WASD／矢印キーで移動、`Z`で点灯中の能力を強化、`Space`でノヴァ、`P`で一時停止、`M`でBGM切替、`F`で全画面。装備の6択操作、`X`／`Tab`での選択は**ありません**。
- **ゲームパッド：** 左スティック／十字キーで移動、`A`で手動強化、`B`でノヴァ、`START`で開始・一時停止・再開。標準Gamepad API対応ブラウザ向け。PC・Android・iPhoneの全機種での接続保証ではありません。

全画面表示ではブラウザが許す場合のみ横向きへの自動切替を試みます。対応しない端末では縦画面のまま遊べます。画面が見切れる場合はブラウザを再読み込みし、新しいCSSを取得してください。

## グラディウス式パワーメーター

パワーカプセルを1個拾うごとに6色メーターの点灯が自動で1つ進みます。

`BOOST → SPREAD → LASER → MISSILE → OPTION → SHIELD → BOOST …`

**拾っただけでは強化されません。** 右の「強化」、PCの`Z`、パッドの`A`を明示操作したときだけ点灯中の能力が1段階上がり、メーターは空に戻ります。メーターは表示専用で、直接タップして選択する方式ではありません。ボス報酬の無料強化券も自動消費しません。

ノヴァは右ボタン（PC `Space`、パッド `B`）で発動。使用後は60秒ごとに1回補充。ゲーム終了後に残り秒数が進み続ける仕様ではありません。

## 2026-10-31｜ボス2倍・敵の動的難易度・編隊引き継ぎ（最新）

- **ボス耐久は直前の2倍**。攻撃装備による従来の倍率に加えて最大16.4倍（元の基礎耐久比）。通常戦闘の攻撃頻度も約22%増加。**ボス戦中の武器強化にも随時追従**し、削ったHPの割合は維持。反応装甲、反撃予告、コア露出、17種類の特殊攻撃とフェーズ変化は維持。
- **雑魚敵の強さは動的**。武器構成を主に（85%）、機体レベルを補助的に（15%）参照。HPは戦況に応じた倍率で最大約5.4倍（元の各面基礎値比）、装甲・移動速度・攻撃間隔・弾速も変動。既に画面にいる敵も強化・耐久低下に追従し、削ったHPの比率を維持。破壊済み装甲は復活しない。
- **ボス出現時は敵を消去しない**。出現中の雑魚と発進待ちの編隊はそのまま飛来・攻撃する。新規の通常編隊の生成だけ停止。残敵の整理はボス撃破後。
- **連続射撃回帰**：60FPSの仮想戦闘（プレイヤーは計測のため無敵、最大強化）では8面のサンプルで撃破約27～90秒、ボスは全員撃破可能。17ボスの弱／最大装備比較、既存敵の強化・弱体化、編隊維持、破壊済み装甲を検査。実機での難易度・クリア率・端末別FPSは未確認。
- **対象**：games/star-fighter/のみ。進捗35/36、毎時自動タスクは停止維持。

## ボス瞬殺対策：実弾テスト済み（2026-10-31・以前の実装記録）

- **原因を修正：** LASERの貫通弾が同じボスの当たり判定内に残ると毎フレームダメージを与えていました。現在は**同じ弾が同じ対象に当たるのは1回だけ**。別の敵へ貫通する性質は残します。
- **反応装甲：** 強化機体の連続攻撃を受けたボスは青いエネルギー障壁を短時間展開、狙いを予告して反撃。回避後は装甲が破れて弱点が露出し、攻撃が通りやすくなります。単なる長時間無敵ではなく撃破可能。
- **強化への追従：** ボスの基礎耐久は攻撃装備指数に応じて最大8.2倍。低火力構成は従来HPから開始。低耐久のプレイヤーには防御を緩めます。
- **60FPS戦闘模擬：** 最大攻撃装備・OVERDRIVE・自動射撃・誘導ミサイルを使用し、毎フレーム実弾判定を実行。ボス8体の撃破時間は**約13～44秒**、いずれも1秒・2秒の瞬殺なし。パイロットのみ無敵としてボス耐久を切り分けたテストです。実機操作での生存率・体感難易度は未計測。
- **変更範囲：** games/star-fighter/のみ。双方無敵のボス練習、全17ボス、300トロフィーは維持。毎時開発タスクは停止維持。

## 戦闘難易度の自動調整（2026-10-30・旧調整記録）

- **攻撃装備に合わせた難易度：** SPREAD / LASER / MISSILE / OPTION と連射モジュールの強化状況から敵とボスの耐久を決定。シールド・BOOST・機体耐久Lvだけを上げても敵は硬くなりません。戦闘中に敵が突然回復することはなく、出現時に強さを固定します。
- **ボスの対策：** 最大武器構成ではボスの耐久を最大約5.2倍まで調整。装甲が閉じている間はダメージを減らし、開くとダメージが増加。ボス本体の上下装甲板が開閉を表示します。低耐久時は装甲の防御効果が弱まり、通常プレイで撃破できます。
- **雑魚の手応え：** 強化機体に応じて敵の耐久は最大約3.15倍。一部の重装機・特殊な小型機は有限の装甲を持ち、破壊すると横に回避して予告つきで反撃します。軽い敵はすべて重装化しません。画面外にいる敵は自機の弾・ノヴァ・ミサイル爆風で撃破されません。
- **デバッグ：** ボス対決のみでは従来どおり双方無敵。機体Lv25・NOVA60秒・トロフィー300個は維持。
- **回帰検査：** 17体のボスを弱武装・最大武装で比較、通常敵の装甲破壊から反撃、画面外命中の防止、最大武器20斉射＋ミサイル＋NOVA相当の集中攻撃でもボスが残ること、既存100シード×8面の模擬検証を実施。**実スマホでのクリア率・爽快感・難易度は未確認**。

## ステージ・ボス・航路

1. ORBITAL FIELD — 外縁軌道
2. IRON CORRIDOR — 機械回廊
3. DEEP NEBULA — 深宇宙
4. BURNING STRATUM — 灼熱宙域
5. FROZEN GRAVE — 氷結残骸帯
6. RELIC BELT — 古代遺跡帯
7. ABYSSAL GATE — 異界境界

航路分岐を含めて**17種類の大型ボス**。第4ステージ補給航路では、シードにより機械カニ「MOLTEN CRAB」かメカサソリ「SCORPION DREAD」が出現します。どちらもデバッグで選択可能。追加した機械生物の雑魚敵は「CLAMP CRAB」「STINGER SCOUT」「MANTIS REAPER」の3種類で、編隊の総数を増やさず既存の敵の一部と入れ替わります。航路選択で背景・敵・イベント・報酬・ボスが変化し、同じシードで再挑戦できます。各面に独自のWeb Audio BGMとボス用アレンジがあります。OVERDRIVE、GRAZE、周回限定パッシブと武器シナジー、4種類の記章も実装しています。

ボス17体には各4種類、合計68種類の専用アクションがあります。主砲・触手・ハサミ・尾砲・装甲・氷壁・重力弾など、攻撃前に予兆を表示し、攻撃開始後は個別の発射位置・弾道・曲線弾を2回に分けて撃ちます。強化形態は3回に増えます。デバッグの「ボス対決のみ」では自機とボスの双方無敵を維持します。**実機での体感難易度は未確認です。**

**ボス撃破後もゲームは停止しません。** 飛行中の約2.4秒で上・中・下の3択報酬、続く約2.4秒で上／下の2択航路を**機体の上下位置**で選びます。大きな停止メニュー、SAFE/DANGERの文字、赤い誘導ナビゲーターはありません。敵は短い間隔で継続出現します。

## 耐久・機体レベル・難易度

**残機制は廃止**しました。耐久120/120、機体レベル1で開始し、耐久0で即ゲームオーバーです。敵を倒してXPを獲得し、機体レベルは25まで上昇。1レベルにつき最大耐久+8、レベル上昇時に耐久11回復。最大レベル25の耐久上限は312です。武器強化は従来どおりプレイヤーの手動操作のみです。

ステージ1〜8の基本被弾ダメージは13・14・15・16・18・19・21・23。補給航路では約6%軽減、危険航路では約8%増加（第1面は例外）。大型弾は追加ダメージ。被弾後の無敵時間は約1.1秒。修復報酬は通常+36、希少+60、補給航路の再整備+27。偶数セクター突破時の低耐久救済は+22。危機時の敵出現圧力を調整します。**実プレイでの「やや難しい」達成度は未検証**です。

## 途中再開と記録

`localStorage`へセクター開始位置などのチェックポイントとハイスコア、記章を保存。v2セーブには機体レベル・XP・最大耐久・現在耐久を記録します。旧v1セーブは旧HP1〜3の比率を最大耐久120に換算して読み込み、残機は引き継がれません。タイトルの「続きから再開」でセクター開始位置から再開します。**戦闘途中の機体位置は復元しません。** ゲームオーバー・全8面クリア後は通常チェックポイントを消去します。シード欄には8桁以内の16進数を入力できます。

## 隠しデバッグ（テスト用）

**タイトル画面の「STAR FIGHTER」ロゴを合計7回タップ**するとデバッグパネルが開きます。時間制限はありません。途中で回数表示は行わず、7回目にメニューが現れます。

デバッグパネルでは**「ステージ攻略」**と**「ボス対決のみ」**を切り替えられます。

- **ステージ攻略：** 8ステージ・2航路を選び、無敵で通常のステージを遊ぶ。一時停止中も移動可。
- **ボス対決のみ：** 現行17種類のボスから1体選び、雑魚編隊・地形・ステージ道中を飛ばして**即ボス戦**。**自機もボスも完全無敵**で、ボスHPは減りません。攻撃予兆・弾幕・部位演出を繰り返し練習できます。約18秒で第2形態、最終面は約36秒で第3形態になり、約60秒で第1形態へ戻る循環式です。通常よりボス攻撃間隔を約20%短縮し、練習の待ち時間を減らしています。終わるときはポーズ／タイトルへ戻り、同じ個体を最初から再戦・別の個体を選択できます。**ボス撃破判定・戦績・トロフィーの獲得は発生しません。**
- **ゲームパッド：** 解放後、ステージ攻略では十字キー左右で面・上下で航路、ボス対決では左右で17ボスを切り替え、`Y`で出撃・移動。通常の`START`による一時停止・再開も利用可。再戦は一時停止メニューで同じボスを選んで実行。

メカサソリ「SCORPION DREAD」を含む17種類のボスを選択できます。旧機械カニ「MOLTEN CRAB」も残しています。自機・ボス双方無敵はこの練習モードだけに適用します。

デバッグ中のスコア、記章、通常チェックポイントは保存・上書きしません。デバッグ解放はブラウザのそのセッションだけで、通常出撃では無敵が解除されます。
