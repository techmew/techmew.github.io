# STAR FIGHTER — 操作・検証ガイド

8ステージのオリジナル横スクロールSTG。HTML5 Canvas 2D / JavaScript / Web Audioのみで動作し、第三者の音源・画像・外部ライブラリは使用しません。

**公開先：** https://techmew.github.io/games/star-fighter/

**開発状況（2026-10-30）：35/36、8/8ステージ実装済み。v1.0完成判定は保留。** 自動回帰テストは通過していますが、Android/iPhoneの実機表示、Bluetoothゲームパッド、入力遅延・FPSは未測定です。タイトルの「PREVIEW / QA」はこの状態を示します。36工程の正本は `DEVELOPMENT_PLAN.md` です。

## 操作

スマートフォンは**縦・横の両方**でプレイ可能。画面上部に「タイトル」「一時停止／再開」「最大化」「BGM」「縦横切替」、左に広い相対移動タッチパッド、右に**ノヴァ／強化の2ボタン**があります。射撃は自動です。

- **スマホ移動：** 左パッドを指でスワイプ。指の動いた分だけ機体が動き、触れた位置にワープしません。指を離せば停止。
- **PC：** WASD／矢印キーで移動、`Z`で点灯中の能力を強化、`Space`でノヴァ、`P`で一時停止、`M`でBGM切替、`F`で全画面。装備の6択操作、`X`／`Tab`での選択は**ありません**。
- **ゲームパッド：** 左スティック／十字キーで移動、`A`で手動強化、`B`でノヴァ、`START`で開始・一時停止・再開。標準Gamepad API対応ブラウザ向け。PC・Android・iPhoneの全機種での接続保証ではありません。

全画面表示ではブラウザが許す場合のみ横向きへの自動切替を試みます。対応しない端末では縦画面のまま遊べます。画面が見切れる場合はブラウザを再読み込みし、新しいCSSを取得してください。

## グラディウス式パワーメーター

パワーカプセルを1個拾うごとに6色メーターの点灯が自動で1つ進みます。

`BOOST → SPREAD → LASER → MISSILE → OPTION → SHIELD → BOOST …`

**拾っただけでは強化されません。** 右の「強化」、PCの`Z`、パッドの`A`を明示操作したときだけ点灯中の能力が1段階上がり、メーターは空に戻ります。メーターは表示専用で、直接タップして選択する方式ではありません。ボス報酬の無料強化券も自動消費しません。

ノヴァは右ボタン（PC `Space`、パッド `B`）で発動。使用後は60秒ごとに1回補充。ゲーム終了後に残り秒数が進み続ける仕様ではありません。

## ステージ・ボス・航路

1. ORBITAL FIELD — 外縁軌道
2. IRON CORRIDOR — 機械回廊
3. DEEP NEBULA — 深宇宙
4. BURNING STRATUM — 灼熱宙域
5. FROZEN GRAVE — 氷結残骸帯
6. RELIC BELT — 古代遺跡帯
7. ABYSSAL GATE — 異界境界
8. LAST HORIZON — 最終宙域

航路別を含めて**15種類の大型ボス**。航路選択で背景・敵・イベント・報酬・ボスが変化し、同じシードで再挑戦できます。各面に独自のWeb Audio BGMとボス用アレンジがあります。OVERDRIVE、GRAZE、周回限定パッシブと武器シナジー、4種類の記章も実装しています。

**ボス撃破後もゲームは停止しません。** 飛行中の約2.4秒で上・中・下の3択報酬、続く約2.4秒で上／下の2択航路を**機体の上下位置**で選びます。大きな停止メニュー、SAFE/DANGERの文字、赤い誘導ナビゲーターはありません。敵は短い間隔で継続出現します。

## 途中再開と記録

`localStorage`へセクター開始位置などのチェックポイントとハイスコア、記章を保存。タイトルの「続きから再開」でセクター開始位置から再開します。**戦闘途中の機体位置は復元しません。** ゲームオーバー・全8面クリア後は通常チェックポイントを消去します。シード欄には8桁以内の16進数を入力できます。

## 隠しデバッグ（テスト用）

**タイトル画面の「STAR FIGHTER」ロゴを合計7回タップ**するとデバッグパネルが開きます。時間制限はありません。1〜6回目には`SECRET 1/7`〜`6/7`と進捗を表示。開放後は全8ステージ・2航路を選んで**無敵出撃**でき、一時停止中のステージ移動も可能です。ゲームパッドでは解放後、十字キーでステージ／航路を変更し、`Y`で出撃・移動できます。

デバッグ中のスコア、記章、通常チェックポイントは保存・上書きしません。デバッグ解放はブラウザのそのセッションだけで、通常出撃では無敵が解除されます。

## テスト・未検証事項

```sh
node --check game.js
node --check music.js
node --check enemies_plus.js
node --check fullscreen.js
node --check qa_100_runs.js
node qa_100_runs.js
```

仮想DOM/Canvas回帰は100シード×8面、16種類の通し航路、128ボス戦、分岐、15ボス、タッチ・パッド入力、装備・ノヴァ、セーブ、音声、デバッグ記録隔離を検査します。**仮想検査は実機のFPS、入力遅延、タッチの押下感、Bluetoothゲームパッドの相性、iPhone Safari、公開GitHub Pagesの反映を証明しません。** 実機QAが未完の間はv1.0完成と表記しません。
