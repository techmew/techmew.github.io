# STAR FIGHTER

オリジナルの横スクロールシューティングゲーム。HTML / Canvas 2D / JavaScript のみで動き、外部ライブラリやアセットは不要。

## Play
https://techmew.github.io/games/star-fighter/

## 操作
- **PC**: WASD / 矢印キーで移動、X で強化項目の選択、Enter / Z で強化、Space で衝撃波、P で一時停止、M で音声切替
- **スマートフォン（横画面専用）**: 左スティックで移動。画面下の装備ボタンをタップして強化。PULSE ボタンで衝撃波
- 自動射撃。パワーカプセルを集め、BOOST / SPREAD / LASER / MISSILE / OPTION / SHIELD を選択して「強化」で購入（残額保持）

## 初期収録
- 3つのエリアと独立した背景演出
- 3種類の大型ボスと複数の攻撃パターン
- 敵の編隊、予告付き突撃敵、誘導ミサイル、僚機、貫通レーザー、バリア、衝撃波
- ボスは耐久力55%以下で第2形態に突入し、予告付きビームと新しい弾幕を使用
- 敵撃破・敵弾かすり回避でOVERDRIVEが蓄積。発動時8秒間、火力・連射・得点が増加
- GRAZE（弾かすり）ボーナス、MAX CHAIN記録、スコア倍率
- スコアとコンボ倍率、ローカル保存のベストスコア
- プロシージャル描画・パーティクル・オリジナルのサイバーテクノBGM（3ステージ＋ボスアレンジ）
- モバイル横画面専用、キーボード操作、一時停止

## BGM
Web Audio API でリアルタイム合成する完全オリジナルのサイバー系BGMです。音源ファイル・外部楽曲・第三者サンプル不使用で、ゲーム内で無償利用できます。

## 分岐航路（開発工程 01）

ボス撃破後に2航路から選択します。安全航路は編隊が小さく、敵の出現・攻撃が緩やかで、回収範囲と物資ドロップが増加します。危険航路は高速編隊・迎撃機・重装敵の出現率、敵の耐久・攻撃頻度、ボス耐久が増加する代わりに、カプセル2個・撃破得点+25%・オーバードライブ蓄積を獲得します。両ルートとも敵数の上限を設け、ステージ2・3の背景色と編成も変化します。PC は 1 / 2 キー、スマートフォンは2枚のカードをタップして選択できます。

## 航路マップ（開発工程 03）

ボス撃破後の航路選択画面に、3セクターのマップ・踏破した経路・現在地・次の分岐を表示。現在地は青緑色の機体マーカー、踏破経路は緑色の線、選択可能な経路は青または橙の破線。画面上部のエリア表示は現在の航路名に変わります。PCの左右キーで選択中のカードとマップの強調表示が同期します。

## シードによる再現（改修 04）

- タイトルの SEED 欄を空欄にして開始すると、毎周新しい8桁の16進シードを生成します。8桁以内の16進数を入力すると指定シードで開始できます。
- ゲームオーバー／クリア画面にシードを表示し、「同じ配置で再挑戦」で再利用できます。URL の `?seed=1A2B3C4D` でも指定できます。
- 敵編隊の抽選、敵初期パラメータ、発射間隔、補給位置・ドロップは、ステージ・航路ごとに分離したシード付き乱数を使います。パーティクル・描画・BGMの乱数消費は敵配置を変えません。
- 再現の条件：**同じシード、同じ航路、同じプレイヤー行動・経過時間**。フレーム時間や撃破順序が異なる場合、出現回数・ドロップのタイミングは変化し得ます。完全なリプレイ記録やフレーム固定シミュレーションは未実装です。

## 航路連鎖とランダムイベント（改修 05）

- シードと直前の航路に応じて、次の2つの航路名と固有イベントを生成します。航路マップは未到達地点を「未発見」とし、次の候補だけを表示します。
- 安全航路のイベント：漂流物資、修復ビーコン、旧式補給庫、青い共鳴。戦闘途中に補給や防御・ドライブ回復が発生します。
- 危険航路のイベント：追撃隊、プラズマ嵐、武装貨物船、重力の裂け目。戦闘途中に特殊編隊が登場し、光る精鋭を倒すとカプセルを確定獲得します。
- 同じ危険度の航路を2回連続で選ぶと連鎖ボーナス：安全×2はバリア+1、危険×2はドライブ+20（ただし危険イベントには追加敵1機）。航路カードでイベントを確認でき、PC 1/2 またはタップで選択できます。
- イベントはゲーム進行時間で1回のみ発生。シードと分岐を再利用すると同じイベントを再現できます。
