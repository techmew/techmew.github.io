# ゾンビは殴ればいい
日本の地方都市が舞台の主観視点・ゾンビ物理アクションゲーム。
作品は「WILD RECLAIM」と独立。英語名・中二病設定・決めゼリフは採用しない。

## 遊ぶ
https://techmew.github.io/zombie/

## 操作
PC：WASD 移動、マウス 視点、左クリック パンチ、右クリック または Q キック、F 体当たり、E 近くの物を拾う／投げる、Shift 走る、Space 跳ぶ。R 昼夜切り替え、T 雨切り替え（試験用）。
スマホ：左側の円形スティックで移動、右側の画面を指で動かして視点変更、専用の攻撃ボタンを使用。

## 2026-11-01 初期実装
・道路と16棟の建物からなる自由探索区域、入口から入れる室内
・ゾンビ複数種（通常、走る、大柄、叫ぶ、四つん這い）と大型怪物
・パンチ、キック、体当たり、ノックバック、転倒と敵同士の簡易衝突
・椅子や棚などを拾って投げる。飛んだ物体によるダメージ、車の警報の音で敵が集まる
・牛乳を買って家に帰る任意の用事／体力・スタミナ／簡易成長／地図
・スマホ視点・移動・行動ボタン
・時間帯・悪天候の演出は現在、主に明るさ変化のみ

## 未実装・次の開発
複数地区のつながりと街規模の拡張、雨粒・停電・店内照明、ゾンビ固有の日常行動、巨大怪物の多種類化、家具や建物の本格破壊、物理ラグドール、高度なAI、生存者と依頼、セーブとロード、レベル100、本格的な効果音、品質検証。
