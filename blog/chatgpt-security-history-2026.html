AI UPDATE / CHATGPT

ChatGPTにSecurity history追加｜不審なログイン・MFA変更を確認する方法

アカウントで起きたセキュリティ関連イベントを後から確認できる場所が追加されました。

Security historyで確認できるもの

OpenAIは2026年9月25日のChatGPT更新でSecurity historyを追加しました。サインイン、サインアウト、MFA、パスキーなどのセキュリティ設定変更を時系列で確認できます。イベントには時刻、場所、端末情報が表示される場合がありますが、一部は概算または取得できない場合があります。

Webでの確認場所

  1. ChatGPTのSettingsを開く。
  2. Security and loginへ進む。
  3. Security historyを開く。
  4. 日時、端末、場所、変更内容を確認する。

身に覚えのない履歴があった時

自分の別端末、VPN、モバイル回線などと整合するかを先に確認します。明らかに心当たりがなければ、ログイン方法、パスワード、MFAなどの保護設定と、他端末のセッションを確認します。

位置だけで侵入を断定しない

IPベースの位置情報は正確な住所ではありません。VPNや回線事業者の構成で別地域に見えることがあります。Security historyは複数の情報を組み合わせて確認するための材料として使います。
