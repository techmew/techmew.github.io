ChatGPTにSecurity history追加｜不審なログイン・MFA変更を確認する方法

NEW2026.09.27 公開

Security historyで確認できるもの

OpenAIは2026年9月25日の更新でSecurity historyを追加しました。サインイン、サインアウト、MFA、パスキーなどのセキュリティ設定変更を時系列で確認できます。

Webでの確認場所

  1. ChatGPTのSettingsを開く。
  2. Security and loginへ進む。
  3. Security historyを開く。
  4. 日時、端末、場所、変更内容を確認する。

身に覚えのない履歴がある時

別端末、VPN、モバイル回線などと整合するかを先に確認します。心当たりがなければログイン方法、パスワード、MFA、他端末のセッションを見直します。

位置表示だけで断定しない

IPベースの位置は正確な住所ではありません。VPNや通信事業者の構成で別地域に見えることがあります。
