AI UPDATE / GITHUB COPILOT

GitHub CopilotのSlack・Teams連携が強化｜添付・類似Issue・モデル切替に対応

会話からGitHub作業へ渡せる文脈が増え、Issue作成やモデル選択の流れも改善されました。

Slack・Teamsから渡せる文脈が増えた

GitHubは2026年9月25日、GitHub CopilotのSlack・Microsoft Teams連携を更新しました。Slackではファイル、添付、メッセージリンクを文脈として扱える範囲が広がり、Teamsでもインライン画像、転送メッセージ、チャンネルやスレッド履歴などを扱いやすくなっています。

Issue作成前に類似Issueを確認

新しいIssueを作る前に類似Issueを確認する機能も追加されました。重複報告を減らし、既存Issueへ合流しやすくする変更です。作業結果と元の会話を相互にたどるリンクも強化されています。

スレッド途中でモデル切替

次のメッセージから使うモデルを切り替え、その選択をスレッド内で保持できます。Slackでは既定のownerやrepositoryを設定する機能も追加されています。

導入時に見る点

  • どのチャンネル・チームからGitHub操作を許可するか。
  • 既定repositoryを誤った場所へ向けていないか。
  • 添付に秘密情報が含まれていないか。
  • Issue作成やコード変更の結果リンクを確認する。
