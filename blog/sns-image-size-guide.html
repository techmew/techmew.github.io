SNS画像サイズを一度に作るための一覧

SNSごとに推奨サイズが違うため、同じ画像でも1200×630、1080×1350、1600×900など複数の書き出しが必要になります。ここでは2026年9月時点で確認できる公式値と、実作業で使いやすい制作プリセットを分けて整理します。

複数サイズを一括生成する

先に結論：公式値と便利なプリセットは分けて考える

SNSの画像仕様には「サービスが公式に推奨している寸法」と、「投稿制作で広く使われる比率・寸法」が混在します。全部を公式値のように書くと、更新された瞬間に嘘になります。SNS Image Studioでは、公式に確認できるものは明記し、Instagramなどは一般的な制作プリセットとして扱っています。

X

X公式ヘルプは、プロフィール画像を400×400、ヘッダー画像を1500×500の推奨寸法として案内しています。プロフィール／ヘッダーはJPG・GIF・PNGに対応しますが、アニメーションGIFはプロフィール／ヘッダーでは使えません。

X公式：プロフィールのカスタマイズ

YouTube

YouTube公式ヘルプは、チャンネルバナーの推奨サイズを2560×1440、最小アップロードサイズを2048×1152、テキストやロゴの安全領域を1235×338としています。端末によってバナーの見える範囲が変わるため、画像全体の中央に重要情報を置く設計が必要です。

YouTube公式：チャンネルのブランディング

LinkedIn

LinkedIn公式ヘルプでは、会社・団体ページのロゴ推奨サイズが400×400。URL付き投稿のカスタム画像は1.91:1（1200×627）と案内されています。ページのカバー画像はデバイスによってトリミングされる場合があるため、重要な情報は中央寄せが安全です。

LinkedIn公式：画像仕様

Instagram

制作では正方形1080×1080、縦長1080×1350（4:5）、Story / Reels向け1080×1920（9:16）を用意しておくと扱いやすいです。ただし、これらを「すべての投稿でMetaが固定指定している唯一のサイズ」とは扱いません。表示UIや対応比率は変わり得るため、重要な文字や顔を端へ寄せすぎないのが実務上の保険です。

ブログ・OGP

Web記事のシェア画像には1200×630の1.91:1が広く使われます。SNS側で多少クロップされることを前提に、タイトル文字は四辺ぎりぎりへ置かず中央寄りにします。

1枚から複数サイズを作るときの順番

  1. 元画像はできるだけ大きいものを使う。
  2. 先に必要な出力先をすべて選ぶ。
  3. 顔・商品・タイトルなど「切れて困る位置」を焦点として決める。
  4. バナー系はセーフエリアを確認する。
  5. Coverで切れすぎる素材はFitへ切り替え、背景色またはぼかしで埋める。
  6. 最後にJPG / PNG / WebPを選び、生成後のピクセル寸法を確認する。

SNS Image Studioはこの流れをひとつの画面で行い、複数画像×複数サイズをまとめて生成します。生成後は寸法を再検証し、個別またはZIPで保存できます。

画像を外部へ送らない

このツールはCanvasを使い、画像加工をブラウザ内で行います。SNS画像には人物や未公開商品などを使うこともあるため、単なる便利機能より「どこへ送られるか分かる」ことのほうが重要です。写真のGPS位置情報も気になる場合は、公開前にExif Cleanerで確認できます。
