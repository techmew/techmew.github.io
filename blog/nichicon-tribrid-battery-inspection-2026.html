ニチコンT3蓄電池で発煙・発火のおそれ｜対象型番と無料点検を確認

2026年9月26日NEW

ニチコンは2026年9月24日、家庭用「トライブリッド蓄電システム T3シリーズ」の一部電池について無料点検を案内した。製造上の不具合により、ごくまれに発煙し、最悪の場合は発火に至るおそれがあるとしている。対象かどうか分からない家庭は、まず本体や保証書の型番を確認したい。

先に要点
  • 2023年8月〜2024年4月に出荷された一部のT3シリーズ電池が対象。
  • 電解液漏れや発煙事象が確認され、最悪の場合は発火のおそれがある。
  • ニチコンは対象品を無料点検し、必要に応じて対応する。
  • 自己判断で分解・修理はせず、対象確認後は専用窓口へ連絡する。

何が起きている？

ニチコンの案内では、T3シリーズに搭載された一部の電池について製造上の不具合が判明した。消費者庁のリコール情報でも、電解液漏れや発煙が発生したとして、点検・交換対応が案内されている。

蓄電システムは設置後に本体を頻繁に触る製品ではないため、普段問題なく動いている家庭でも型番確認はしておいた方がいい。異臭・異音・煙などの異常がある場合は、機器に近づいて無理に操作せず、販売店やメーカー窓口の案内に従う。

対象として案内されている型番

区分型番
T3システム例ESS-T3S1 / ESS-T3S1V / ESS-T3S1VP / ESS-T3S1VPL / ESS-T3M1
消費者庁掲載の電池ユニットES-T3MCK / ES-T3XCK / ES-T3S1 / ES-T3L1 / ES-T3M1 / ES-T3X1 / ES-T3SS / ES-T3LS

型番だけで対象可否が確定しない場合がある。出荷時期や製造番号も含めてメーカー側で確認するため、該当しそうなら窓口へ問い合わせるのが確実だ。

今やること

  1. 蓄電システム本体・保証書・施工資料で製品型番を確認する。
  2. ニチコン公式の「T3シリーズ 電池部の点検のお知らせ」で対象条件を確認する。
  3. 該当または判断できない場合は専用窓口へ連絡する。
  4. 点検まではメーカーから個別の指示があれば従う。自分で筐体を開けない。
ニチコン専用窓口

電話：0800-123-3993
受付：9:00〜17:00。公式案内では土日祝も受け付け（年末年始を除く）。最新の受付状況は公式ページを優先。

中古住宅・中古蓄電池でも確認した方がいい

設置した本人でなくても、住宅購入時に蓄電池が付いていたケースや、施工会社が変わったケースはある。型番が一致する可能性があれば、前所有者の購入履歴が分からなくてもメーカーへ確認した方が早い。

まとめ

今回の案内は、T3シリーズのすべてが危険という話ではなく、特定時期に出荷された一部電池の点検対応だ。ただし発煙・発火につながる可能性がある安全案件なので、対象型番を放置する理由はない。まず型番を確認し、該当する可能性があれば無料点検の窓口へ連絡しよう。
