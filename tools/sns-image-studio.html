SNS Image Studio

X、Instagram、YouTube、LinkedIn、ブログOGP向けに、同じ素材を何度も開いてリサイズする作業をまとめる無料ブラウザツールです。複数画像と複数サイズを選び、一括で書き出せます。

SNS Image Studioを開く

できること

最大50枚のJPG・PNG・WebPを読み込み、X、Instagram、YouTube、LinkedIn、OGPなどの複数プリセットへ一括変換します。画像ごとに「残したい位置」を指定でき、Cover / Fit、背景色・ぼかし・透明、画質、JPG / PNG / WebPを選べます。

生成後は出力画像を再読込してピクセル寸法を検証します。個別保存とZIP一括保存に対応し、失敗したファイルは成功扱いしません。

焦点位置とセーフエリア

Coverでは縦横比の違いによって画像の一部が切れます。プレビューをタップまたはドラッグし、顔・商品・文字など「絶対に残したい位置」を画像ごとに設定できます。YouTubeバナーは公式のテキスト・ロゴ安全領域を重ねて確認できます。Story / ReelsのガイドはアプリUIを避ける作業上の目安として表示し、公式固定値とは区別しています。

画像はアップロードする？

画像の読み込み、切り抜き、リサイズ、形式変換はブラウザのCanvasで行います。himanekoの自前サーバーへ画像をアップロードする処理はありません。ZIP生成にJSZip 3.10.2を使用します。

画像スリムとの違い

画像スリムは容量や任意サイズへの軽量化が中心です。SNS Image Studioは「ひとつの素材から複数媒体サイズを一度に作る」こと、焦点とセーフエリアを確認することに特化しています。写真のGPSやExifを消したい場合はExif Cleanerを使えます。

利用ライブラリ

ZIP生成：JSZip 3.10.2。画像処理はブラウザ標準のCanvas APIを使用します。JSZipはMITまたはGPL-3.0-or-laterのデュアルライセンスです。
