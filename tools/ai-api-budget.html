AI API料金・月額予算シミュレーター

複数のAIモデルの料金を、トークン数・実行回数・円換算レートから横並びで比較する無料ツールです。

無料ツールを使う →

誰に役立つ？

AIチャットボット、文章要約、自動分類、エージェントを開発している人が、月額予算超過を公開前に見積もるための道具です。既存のAI Handoff Builderは引継ぎ文章を生成するツールですが、こちらはトークン課金の計算に特化しています。

主な機能

  • 最大12候補の単価・回数・キャッシュ率を横並び比較
  • 1回、1日、月額のドル/日本円換算と予算に収まる回数を表示
  • 月額比較グラフ、CSV書出、設定JSON書出・読込
  • 必要なときだけ端末内への手動保存・復元・削除

使い方

  1. 公式料金表等で利用予定モデルの入力/キャッシュ入力/出力単価を確認する。
  2. 1回あたりトークン数、1日の呼び出し回数を入力する。
  3. 為替、日数、月予算を設定し、月額・予算内回数を確認する。
  4. CSVで共有するか、JSONで比較条件を保存する。

計算の前提

非キャッシュ入力＋キャッシュ入力＋出力の従量課金を合算します。すべての料金は100万トークン当たりの米ドルで入力してください。初期値は架空の例です。正確な請求額ではありません。

対応しない費用

キャッシュ書込料金、画像・音声・動画、検索等のツール料金、リージョン別加算、長文コンテキスト料金、税、請求時の為替、実際の最小請求額は対象外です。プロバイダー側の計算仕様と照合してください。

プライバシー

ユーザーが入力した値はこのブラウザ内で処理し、計算のための外部送信は行いません。端末保存ボタンを押した場合のみlocalStorageを使用します。

よくある質問

ChatGPT Plusの月額料金は計算できますか？

できません。APIの従量課金専用です。

キャッシュ率がわからない場合は？

まず0%として安全側の費用を算出し、実績を取得できたら実績値に修正してください。

API単価を自動更新できますか？

このツールは自動更新しません。料金改定を誤認しないため、公式料金を必ず手入力する仕様です。
