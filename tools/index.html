無料Webツール一覧

画像を変換したい、容量を減らしたい、GIFを作りたい、写真の位置情報を消したい。そんな作業を、できるだけブラウザだけで終わらせるためのツールをまとめています。

用途から選ぶ

画像を変換・軽量化 / GIF・APNGを作る / 写真の情報を消す / スタンプ・時計素材を作る

画像を変換・軽量化

無料・公開中

HEIC Lab

iPhoneのHEIC / HEIFをJPG・PNG・WebPへ最大100枚まとめて変換。画質、リサイズ、目標容量、Exif/GPS削除、撮影日リネーム、ZIP保存まで対応。

無料・公開中

画像スリム

PNG・JPG・WebPを一括で軽量化。割合、最大サイズ、指定サイズ、目標KB/MB、形式変換から目的に合わせて調整できます。

今すぐ使う使い方を見る

GIF・APNGを作る

無料・公開中

GIF / APNG Maker

連番PNG・JPG・WebPからGIFまたはAPNGを作成。速度、フレームごとの時間、逆再生、往復、透明背景、色数、リサイズをまとめて調整できます。

今すぐ使う使い方を見る

写真の情報を確認・削除

無料・公開中

Exif Cleaner

写真に残っているGPS位置情報、端末名、撮影日時などを確認してから削除。最大100枚、HEIC/JPG/PNG/WebP、削除後の再検査、ZIP保存に対応。

スタンプ・スマートウォッチ素材を作る

無料・公開中

LINEスタンプメーカー

最大40枚の画像をまとめてスタンプ向けに調整。透過、余白、サイズ、ファイル名、メイン画像、タブ画像、ZIP保存まで一度に処理できます。

スタンプを作る使い方を見る
無料・公開中

Watch Motion Studio PRO

スマートウォッチ向けの動画分割、連番画像、容量確認、AOD、文字盤プレビューなどをまとめて扱う制作ツールです。

今すぐ使う使い方を見る

迷ったとき

iPhone写真を普通の画像にしたい → HEIC Lab

画像を200KBなど指定容量へ近づけたい → 画像スリム

連番画像を動かしたい → GIF / APNG Maker

SNSへ出す写真の位置情報が心配 → Exif Cleaner

LINEスタンプ用画像をまとめて整えたい → LINEスタンプメーカー

スマートウォッチ用の連番素材を作りたい → Watch Motion Studio PRO
