X Post Studio

スマホで文章を入力し、元の口調を残したまま、誤字脱字・構成3案・コンプラ・絵文字・関連ハッシュタグをAIでまとめて処理するX投稿サポートツールです。

X Post Studioを開く

できること

元文章の口調をAIが読み取り、別人格に変えずに校正します。誤字脱字・明らかな誤変換の修正、自然 / 反応重視 / 短く強めの3案、絵文字「多い / 中 / なし」、通常投稿 / 長文、関連ハッシュタグ、コンプラ注意をまとめて処理します。

長文は勝手に分割しません。複数のXアカウント名と、各アカウントで使うブラウザ名をスマホ内に保存できます。

利用者ごとにAIを分ける

共通のAIキーを全員で使う仕組みにはしていません。各利用者が自分のCloudflareアカウントでWorkerを作成し、そのWorker URLを自分のX Post Studioへ登録します。AIの無料枠も利用者ごとに分かれます。

Cloudflare Workers AIの無料セットアップ

Cloudflare無料アカウントを作る Cloudflare Dashboardを開く

手順1：Cloudflare DashboardからWorkersを開く

Cloudflare Dashboardを開きます。現在の画面では、中央にある「Workers」を押すのが最短です。左メニューの「コンピュート」→「Workers & Pages」から進んでも同じ場所へ行けます。

手順2：アプリケーションを作成する

Workers & Pages →「アプリケーションを作成する」まで進むと、下の「Make something new」画面が表示されます。

ここでは「Hello World を開始する」を押します。今回はチャット画面付きテンプレートではなく、X Post StudioからPOSTを受けてAI処理結果をJSONで返すシンプルなWorkerを作るため、Hello Worldを土台にしてコードを差し替えます。

この先の流れ

  1. 「Hello World を開始する」を押す。
  2. Worker名を x-post-studio-ai など分かりやすい名前にする。
  3. Workerを作成・デプロイする。
  4. 作成したWorkerで「Edit code」を開き、初期コードを削除する。
  5. X Post Studio用Workerテンプレートを丸ごと貼り付けて保存・デプロイする。
  6. WorkerのSettings → BindingsでWorkers AIを追加し、Binding名を AI にする。
  7. 発行された https://xxxxx.workers.dev をX Post Studioの「AI接続」に貼り付ける。
  8. 「接続テスト」を押して成功すれば完了。
重要：AI Binding名は AI

Workerテンプレートは env.AI を使うため、Workers AI Bindingの名前は必ず AI にします。Cloudflare公式でも、Workers AIをWorkerから使うにはWorkers AI Bindingが必要です。

無料枠について

Cloudflare Workers AIのFreeプランには1日10,000 Neuronsの無料割当があります。無料枠を使い切った場合は、その日の追加AI処理が失敗する設計で、無料プランのまま勝手に従量課金へ移行する前提にはしていません。Cloudflare側の料金・対象モデルは将来変更される可能性があります。

Cloudflare公式：DashboardでWorkers AIを始める / Workers AI Binding公式手順 / Workers AI料金・無料枠

自分のGitHubで使いたい場合

この公開ページを共用する必要はありません。自分のGitHub PagesへHTMLをコピーし、自分のCloudflare Worker URLを登録して使う構成にできます。Worker URLはブラウザのlocalStorageへ保存するため、GitHubのソースへAIキーを書き込む必要はありません。

アカウント切替の扱い

Xのパスワードや認証トークンは保存しません。アカウントボタンは「どのアカウントで投稿するか」と「どのブラウザを使うか」の目印です。投稿時は本文をコピーしてXの投稿画面を開きます。

ここは実機確認が必要

スマホからChrome / Edge / Firefoxなど特定のブラウザを強制して開く方法は、Android・iPhoneと各ブラウザの仕様で挙動が異なります。X APIの有料利用には切り替えず、無料の範囲で実機テストしながら詰めます。

「バズる」について

AIがバズを保証することはできません。X Post Studioでは、冒頭の伝わりやすさ、情報密度、読みやすい改行、余計な前置きの削減、内容に関連するハッシュタグの提案を行います。リアルタイムのXトレンドを取得しているふりはしません。

コンプラチェック

誹謗中傷、差別、個人情報、違法・危険行為、医療や金融に関する強い断定、著作権侵害を助長する表現、根拠のない断定などを注意候補として表示します。AI判定なので、法的判断を保証するものではありません。
