X Post Studio

Xへ投稿する前に、誤字脱字候補、重複、長すぎる1文、NGワード、電話番号・メールらしき文字列を確認し、読みやすい投稿案へ整える無料ツールです。無料枠 / Premium、絵文字量、アカウント別の文体設定を保存できます。

外部AI APIなし・登録不要

入力文章とアカウント設定はブラウザ内で処理・保存します。Xのパスワードやログイン情報は扱いません。

X Post Studioを開く

できること

  • よくある表記ミス、連続記号、重複のチェック
  • 自然 / 冒頭強め / 短文の3案を生成
  • 無料枠280文字 / Premium長文の切替
  • 絵文字ガッツリ / 普通 / なし
  • 複数アカウントの文体、NGワード、ハッシュタグ、CTA設定を端末内保存
  • 長文をスレッド向けに分割
  • コピーまたはX投稿画面へ本文を渡す
  • 直近の生成履歴を端末内に保存

「バズる」に対して何をする？

結果を保証するスコア付けはしません。代わりに、冒頭で内容を把握しやすくする、弱い前置きを減らす、長い1文を分ける、不要な言い回しを圧縮する、投稿目的に応じてCTAを付ける、という編集を行います。外部AIを使わないので、意味を大きく作り変えにくいのも特徴です。

X無料枠とPremium

通常ポストは280文字を基準にし、Premiumでは長いポスト用に最大25,000文字までの設定を用意しています。X側の実際の文字数計算はURLなどで単純な文字数と異なる場合があるため、ツール内は簡易カウントです。

複数アカウントで使う

「メイン」「商品紹介」「制作告知」など、アカウントごとにプロファイルを作成できます。保存するのは表示名メモ、無料/Premium、文体、絵文字量、NGワード、タグ、CTA設定だけです。Xのログインアカウント自体は切り替えません。投稿前にX側の現在アカウントを確認してください。

校正の限界

完全無料・ブラウザ完結を優先しているため、生成AIによる文脈理解型校正ではありません。固有名詞、専門用語、わざと崩した言葉などは判断できない場合があります。公開前の最終確認用として使ってください。
