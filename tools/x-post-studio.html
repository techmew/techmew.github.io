X Post Studio

スマホで文章を入力し、元の口調を残したまま、誤字脱字・構成3案・コンプラ・絵文字・関連ハッシュタグをAIでまとめて処理するX投稿サポートツールです。

X Post Studioを開く

できること

元文章の口調をAIが読み取り、別人格に変えずに校正します。誤字脱字・明らかな誤変換の修正、自然 / 反応重視 / 短く強めの3案、絵文字「多い / 中 / なし」、通常投稿 / 長文、関連ハッシュタグ、コンプラ注意をまとめて処理します。

長文は勝手に分割しません。複数のXアカウント名と、各アカウントで使うブラウザ名をスマホ内に保存できます。

利用者ごとにAIを分ける

共通のAIキーを全員で使う仕組みにはしていません。各利用者が自分のCloudflareアカウントでWorkerを作成し、そのWorker URLを自分のX Post Studioへ登録します。AIの無料枠も利用者ごとに分かれます。

Cloudflare Workers AIの無料セットアップ

X Post Studio用のWorkerコードは、すでにこのGitHubリポジトリ内の /workers/x-post-studio-ai/ に用意してあります。Cloudflare側では、このフォルダだけをWorkerとしてデプロイします。

1. Cloudflare Dashboardを開く

Cloudflare Dashboardへログインします。

2. Workers → Workers & Pagesを開く

Dashboardのホーム画面から「Workers」を押します。見つからない場合は左メニューの「コンピュート」→「Workers & Pages」と進みます。

3. 「アプリケーションを作成する」を押す

Workers & Pages画面で「アプリケーションを作成する」を押します。

4. 「Connect GitHub」を選ぶ

「Make something new」が表示されたら「Connect GitHub」を選び、GitHubとの接続を許可します。

5. GitHubで自分のサイトのリポジトリを選ぶ

今回は techmew/techmew.github.io を選択します。X Post Studio用Workerはサイト本体と同じリポジトリの /workers/x-post-studio-ai/ に独立して配置してあるため、リポジトリを分けなくてもCloudflareのRoot directoryでWorker部分だけを指定できます。

6. Cloudflareのプロジェクト設定を次の値にする

Production branch：main

Build command：空欄

Deploy command：npx wrangler deploy

Root directory：/workers/x-post-studio-ai/

Root directoryが / のままだとサイト本体をWorkerとしてデプロイしようとして失敗します。必ず /workers/x-post-studio-ai/ に変更します。Cloudflare公式でも、1つのリポジトリに複数のプロジェクトを置く場合はRoot directoryでWrangler設定のあるフォルダを指定する方式が案内されています。

7. Worker名について

今回Cloudflare側ですでに作成されたWorker名は techmew-github-io です。そのためGitHub内の wrangler.jsonc も同じ techmew-github-io に設定済みです。Cloudflare側のWorker名とWranglerの name が一致しない場合、Workers Buildsは失敗します。

8. 「Save and Deploy」またはビルド再実行

設定を保存してデプロイします。すでに失敗したプロジェクトを使う場合は、設定を直したあと「ビルドを再試行」します。

9. Workers AI BindingはGitHub側で設定済み

Worker用の wrangler.jsonc には、次のWorkers AI Bindingをすでに入れてあります。

"ai": {
  "binding": "AI"
}

そのため、今回の構成ではCloudflare DashboardからBindingを手動追加する必要はありません。Workerコードでは env.AI として利用します。

10. デプロイ成功後にworkers.dev URLをコピーする

デプロイが成功したら、CloudflareのWorker画面に表示される https://xxxxx.workers.dev をコピーします。

11. X Post Studioへ登録する

X Post Studioを開き、「AI接続」→「設定」へ進みます。Worker URLを貼り付けて保存し、「接続テスト」を押します。

12. 接続成功で完了

接続テストが成功すれば、誤字脱字修正、元の口調を維持した構成3案、絵文字調整、関連ハッシュタグ提案、コンプラチェックをAIで処理できます。

GitHub側はすでに用意済み

/workers/x-post-studio-ai/ には package.json、wrangler.jsonc、src/index.js、READMEを配置済みです。Cloudflare側でコードを手入力する必要はありません。

無料枠について

Cloudflare Workers AIのFreeプランには1日10,000 Neuronsの無料割当があります。利用者ごとに自分のCloudflareアカウントを使うため、AI無料枠も利用者ごとに分離できます。

Cloudflare公式：Workers Builds設定 / Cloudflare公式：Root directory / モノレポ / Workers AI Binding

自分のGitHubで使いたい場合

この公開ページを共用する必要はありません。自分のGitHub PagesへHTMLをコピーし、自分のCloudflare Worker URLを登録して使う構成にできます。Worker URLはブラウザのlocalStorageへ保存するため、GitHubのソースへAIキーを書き込む必要はありません。

アカウント切替の扱い

Xのパスワードや認証トークンは保存しません。アカウントボタンは「どのアカウントで投稿するか」と「どのブラウザを使うか」の目印です。投稿時は本文をコピーしてXの投稿画面を開きます。

ここは実機確認が必要

スマホからChrome / Edge / Firefoxなど特定のブラウザを強制して開く方法は、Android・iPhoneと各ブラウザの仕様で挙動が異なります。X APIの有料利用には切り替えず、無料の範囲で実機テストしながら詰めます。

「バズる」について

AIがバズを保証することはできません。X Post Studioでは、冒頭の伝わりやすさ、情報密度、読みやすい改行、余計な前置きの削減、内容に関連するハッシュタグの提案を行います。リアルタイムのXトレンドを取得しているふりはしません。

コンプラチェック

誹謗中傷、差別、個人情報、違法・危険行為、医療や金融に関する強い断定、著作権侵害を助長する表現、根拠のない断定などを注意候補として表示します。AI判定なので、法的判断を保証するものではありません。
